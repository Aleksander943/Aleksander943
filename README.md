# 👨🏻‍💻 Aleksander De Deus

**Desenvolvedor Full Stack | React, Next.js, Node.js e NestJS**

Sou estudante de Análise e Desenvolvimento de Sistemas e atuo como estagiário de Desenvolvimento Full Stack no DETRO-RJ, contribuindo na construção e manutenção de aplicações web.

Trabalho com desenvolvimento de interfaces, implementação de regras de negócio, integração de APIs REST e persistência de dados. Busco criar aplicações organizadas, escaláveis e com uma boa experiência para o usuário.

## 🚀 Projetos em destaque

### 💰 Expense Tracker — em desenvolvimento

Aplicação Full Stack para gerenciamento financeiro pessoal, com autenticação JWT, dashboard de receitas e despesas, filtros e operações de cadastro, edição e exclusão de transações.

- **Frontend:** Next.js, React e TypeScript
- **Backend:** Node.js, Prisma e PostgreSQL
- [Frontend](https://github.com/Aleksander943/expense-tracker-frontend)
- [API](https://github.com/Aleksander943/expense-tracker-api)
- [Demonstração](https://frontend-theta-rouge.vercel.app)

### 🧰 Service Marketplace

Marketplace de serviços desenvolvido como aplicação Full Stack, com frontend e API separados.

- **Frontend:** React e TypeScript
- **Backend:** Node.js, TypeScript, Prisma, PostgreSQL e Docker
- [Frontend](https://github.com/Aleksander943/service-marketplace-frontend)
- [API](https://github.com/Aleksander943/service-marketplace-api)
